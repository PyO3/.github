# Security Policy

If you think you have identified a security issue with a PyO3 project, please
**do not open a public issue**.

The easiest way to report the vulnerability to the PyO3 team is through GitHub security reporting:
- [for PyO3](https://github.com/PyO3/pyo3/security/advisories/new)
- [for `setuptools-rust`](https://github.com/PyO3/setuptools-rust/security/advisories/new)

Include as much relevant detail as possible, including affected versions,
potential impact, and a minimal reproducible example where possible.

Thank you.
